## Findings from the validation

1. **Count mismatch, UTC DTC.** The DNS draft says "All 39 sampled UTC/DTC hosts". Section 6 lists 42 captured hosts, of which 32 are UTC or DTC hosts and 10 are SIGMAP. The rewrite holds the number back until the population behind "39" is confirmed. Raise in the next Section 5 authoring run.
2. **Evidence matrix gap.** The UTC DTC matrix has no row stating that ROTPRDSRV122 and MOTPRDSRV122 are domain controllers, although the captures show it (`klist` KDC, `nltest` DC list, CONTROLLER36 and MKYTCSILEFT). Add the row before the sentence is authored.
3. **Lint behaviour.** `prose_lint.py` treats configuration file names (`.ps1`, `.csv`) as evidence file names; accept them when they name what the system runs. `term_lint.py` flags "OT AD" in the DNS draft's dependency table; it is target-state wording (DHCP migration for OT AD) and stays.
