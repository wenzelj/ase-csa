## Fix round

`ERRORS=` says why each block goes back (an error, changed evidence, a search result or evidence leads): fix exactly those.

If `ONLY=` is given (for example `B2,B5`), rewrite only those blocks. `ANSWER=` is the current sheet. Write only the listed blocks to `SHEET=`, each with its `## Bn` heading: the framework puts them into the sheet and keeps every other block as it is. Do not edit `ANSWER=`, and do not write the other blocks. The card may be cut to these blocks; the rest of the sheet already passes, so keep names, roles and wording consistent with it.
